## Description
This is a Flask based app that analyses text for sentiment and emotion. It will return the emotion,sentiment and score of the text written by the user. Moreover a random quote would be generated. 

---
### Features
- **Zenquotes**: I used zenquotes for my quotes. Through this a quote is autogenerated based on the sentiment and emotion of the user.
- **Journal:** I created a mood journal where the data is save into SQLite database. In the mood journal the text entered,detected sentiment ,detected emotion and timestamp is save.
- **Juypter Exploration Library:** I imported pipeline(), torch and used a model from hugging face that can return the emotion from the text entered.


---
### What it does
- The user types the message into the text area.
- The Textblob analyses the text polarity and return sentiments. The sentiment is measure as (Positive, Negative, Neutral)
- Hugging Face uses the text classification pipeline to detect the emotions used in the text. 
- A random quote is fetched from ZENQUOTES API
- The entry is saved to a SQLite database called with the relevant timestamp.
- The analysis score generated  to provide the simple numerical representation of the analysis score


**NOTE:** *The score should not be interpreted as medical or psychological diagnosis.*
